# VitalStack social media kit

The social accounts were built for the old site (AI news, tech, digital
health). The new vitalstack.co.in is a free coding school: lessons with live
animations, quizzes, mock tests, roadmaps, games and certificates. This kit
moves every account to that one message.

Images are in `vitalstack-social-kit.zip` (not in git). Bios below are
checked against each platform's character limit.

## What the theme already does
- Footer of every page links to Instagram, LinkedIn, Facebook, X and Threads
  (change them in **Customize → VitalStack: Header & Footer** if a URL changes).
- The site tells Google these profiles belong to it (schema.org `sameAs`).
- Old post links like `vitalstack.co.in/news/<story>/` no longer 404: they go
  to a guide or lesson with the same name, or to the Blog page.

## One message everywhere
- **Name:** VitalStack (add "| Learn to Code" where the name field is searchable).
- **Promise:** Learn to code. Free. Step by step.
- **Proof:** live code animations, 280+ lessons, 17 mock tests, roadmaps,
  games, free certificates.
- **Subjects:** Java, Python, HTML & CSS, JavaScript, SQL, Spring Boot, React,
  Angular, DSA.
- **Link:** https://vitalstack.co.in/

Drop "Digital Health" and "AI news" from every bio: they promise content the
site no longer has. AI guides still exist on the site, so AI can stay as a
topic in posts.

## Reels (best reach, especially on Instagram)
Screen-record 15–25 seconds of one animation on your phone (open a lesson →
press Play). Add a text hook on top, for example:
- "Polymorphism explained in 15 seconds"
- "What Spring actually does with your @Autowired"
- "Why React re-renders (visualised)"
- "Binary search, step by step"

End with "Free on vitalstack.co.in". One reel a week is enough to start.

## Weekly rhythm (30 minutes a day)
| Day | Post | From the site |
|---|---|---|
| Mon | Code puzzle ("What's the output?") | Java Output game / lesson quizzes |
| Tue | Reel of an animation | any lesson with a visualizer |
| Wed | Mock test challenge ("Score 20/20?") | `/mock-tests/` |
| Thu | Cheat sheet carousel (3–5 slides) | `/cheat-sheets/` |
| Fri | Roadmap tip / career advice | `/roadmaps/` |
| Sat | Daily challenge + leaderboard screenshot | `/daily-challenge/` |
| Sun | "This week's new lessons" | new lessons published that week |

Post the puzzle answer the next day, reply to every comment in the first
hour, and share each post in your WhatsApp / Telegram study groups.
