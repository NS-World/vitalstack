# VitalStack 4.20.3: "Unlock this lesson" button readable again

## Problem
On locked premium lessons the "Unlock this lesson" button showed green text on a green button.
The lesson-text link rule `.prose a` (link colour + underline) out-ranked `.btn-primary`.

## Fix (CSS only, appended to style.css + rebuilt style.min.css)
- Buttons inside lesson text keep their own colours: primary is white on green, ghost is normal text, and neither is underlined.
- This also covers any other `.btn` placed inside lesson content.

## Tests
- Computed colours: Unlock = white on green, See the track = dark text, no underline.
- Full-site 1068 checks, pages 189, sign-in flow 40/40: all pass.
