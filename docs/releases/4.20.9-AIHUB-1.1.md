# VitalStack 4.20.9 + AI Hub 1.1.0: Motion Studio marketplace, copy limits, AI Pro plans

## Theme 4.20.9 (one additive line)
`vitalstack_pay_plans` filter in `inc/payments.php` (the 5.0 line already had it), so plugins can add plans that use the existing secure checkout. Nothing else changed.

## AI Hub 1.1.0
**Motion Studio, rebuilt like a design marketplace:**
- 7 new original flagship designs:
  - Card Wheel Story (Pro), a pinned scroll story;
  - Pixel Morph Hero (free);
  - Portal Zoom (Pro);
  - Sideways Manifesto (Pro);
  - Infinite Gallery (free);
  - Sphere Gallery (Pro);
  - Mouse Trail CTA (free).
- Total: 23 designs (10 free, 13 Pro). Each flagship has a detailed, structured build prompt (tokens, structure, timeline, responsive rules, acceptance checklist).
- The other designs get a complete structured prompt automatically.
- Tiles show live previews from a CSP-sandboxed view URL. Scroll stories play themselves in the tile (demo mode), load only near the screen and stop when off-screen (fast).
- Pro items: a crown icon only (no "Premium" text) plus a poster image. The detail panel shows a large preview on the left and actions on the right: Copy build prompt, Copy code, Download .html, Full screen, and a copies-left counter.

**Copy limits (enforced on the server, like motionsites):**
- Visitors: 2 free copies, then "Copy without limits" with **Go Unlimited** and **Create free account**.
- Free accounts: 10 copies a day. AI Pro: unlimited, including Pro designs.
- Code and prompts are never in the page HTML; each copy is one REST call (`/wp-json/vsai/v1/copy`). It validates the id, checks the plan and limits, and has a scraping ceiling (120/hour per account or visitor, 3,000/hour per connecting address). The visitor key uses the real connecting address, never a faked X-Forwarded-For.

**AI Pro plans:**
- AI Pro Monthly $9 / ₹399, Yearly $59 / ₹1,999 (most popular), Lifetime $149 / ₹4,999.
- Sold through the theme's Razorpay checkout; prices are editable in Settings → VitalStack Payments.
- Access is stored as the `ai-hub` key in `vs_premium`, so refunds and renewals work like course tracks.
- New page `/ai/pricing/`: ₹/$ switch, Free + 3 plans, honest "save X% vs monthly", comparison table, FAQ, trust row.
- After paying, `/premium/ai-hub/` redirects to the hub with a thank-you message.
- Course plans no longer unlock AI Pro (separate products; see `docs/AI-PRO-PRICING-AND-MARKETING.md`).

**Cleaner UI:** a "Pricing" link and a "Go Unlimited" pill in the header, motionsites-style white/dark pill buttons, and a new lock card.
