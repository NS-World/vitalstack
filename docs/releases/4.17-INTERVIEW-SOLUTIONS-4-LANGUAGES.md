# 4.17.0: interview solutions in Python, Java, C++ and JavaScript

4.17.0 is 4.16.0 plus the change below. The same change is in 5.0.0-dev.

- **Theme zip:** `vitalstack-theme-v4.17.0.zip` (upload over any 4.12.x – 4.16.x)
- **Whole theme change from 4.12.0:** `docs/releases/4.17.0-hotfix.patch`
- The Marketing and Festive plugins are unchanged.

## What's new

All **51 interview problems** (Two Sum to Jump Game) used to show their solution only in Python.
Now the main solution of every problem comes in four languages, as tabs:

**Python | Java | C++ | JavaScript**

- **Remembers the language:** a learner who picks Java sees Java first on every problem (saved on
  their device).
- **Same tools as before:** each tab has the code bar with **Copy**, syntax highlighting, and
  "Try it" for JavaScript. The Python tab keeps its line-by-line explainer.
- **Accessible:** real tabs for screen readers; arrow keys, Home and End move between them.
- **Phones:** the tabs sit two per row at full width, with no sideways scrolling.
- **Without JavaScript or when printed:** all four solutions show one under another, each with
  its language name.
- **Existing lessons:** the code lives in the theme (`data/solutions/`), so the lessons already on
  the site get the tabs straight away. No re-import is needed.

The idea and walk-through stay in Python (one language keeps the explanation simple); the final
solution is the one in four languages. When a lesson shows several solutions (for example brute
force, then heap, then quickselect), the tabs go on the best one.

## How the solutions were checked

Each Java, C++ and JavaScript solution is a full program with the same test calls as the Python
one. The new `tools/check_solutions.py`:

1. runs the lesson's Python solution to get the expected answers;
2. compiles the Java (`javac`, warnings as errors) and C++ (`g++ -std=c++17 -Wall -Wextra`,
   warnings as errors) versions and checks the JavaScript with Node;
3. runs all three and compares their output with Python's (ignoring only formatting differences
   between languages such as `True`/`true`).

**Result: 153 of 153 programs give the same answers** (51 problems × 3 languages).

Each version is written the way that language is normally used, for example `HashMap` and
`ArrayDeque` in Java, `unordered_map`, `priority_queue` and `std::list` in C++, and `Map`/`Set` in
JavaScript (with a small heap where JavaScript has none). The comments match the Python ones.

## Security

- The solutions are read only from the theme's own folder, by a lesson slug checked against
  `[a-z0-9-]`. Nothing comes from the visitor.
- The code is printed escaped (`esc_html`); the tabs script only sets text and attributes (no
  `innerHTML`).
- The Semgrep WordPress rules from 4.16 report nothing on the new files.

## Deploy

1. **UAT:** back up, upload `vitalstack-theme-v4.17.0.zip` → **Replace current with uploaded**.
2. Purge LiteSpeed and the CDN.
3. **Check:** open any interview problem (for example Two Sum). Under "Solution" there are four
   tabs; pick Java, open another problem, and it opens in Java.
4. Then do the same on PROD.
