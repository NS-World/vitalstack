# VitalStack 4.20.8 + AI Hub 1.0.0

## Theme 4.20.8 (fixes)

**Cheat sheets downloaded or printed blank.**
- The certificate's print rule ("hide everything except the certificate") applied to every page, so cheat sheets, lessons and the study plan printed as empty pages.
- The rule now applies only on the certificate page:
  - the certificate still prints alone, A4 landscape;
  - every other page prints A4 portrait with its content and a small "From vitalstack.co.in" line;
  - the floating buttons, cookie note and offer bar are hidden in print.
- Tested: the JavaScript cheat sheet prints as a 6-page A4 PDF with its text, and the certificate prints as 1 landscape page.

**Header search box text wrapped onto two lines** on some laptop widths. It now stays on one line, with "…" if space is tight.
- Tested at every width from 960 to 1920px: 1 line, no sideways scroll.

**New filter `vitalstack_practice_links`** lets plugins add a practice link. The AI Hub uses it.

## VitalStack AI Hub 1.0.0 (new plugin, `plugins/vitalstack-ai-hub`)

A separate AI section with its own dark, neon, 3D design at `/ai/`. The theme is untouched apart from the filter above.

| Page | What's there |
|---|---|
| `/ai/` | Hero with an interactive 3D point-sphere, four 3D tilt "doors", plan band, picks |
| `/ai/library/` | 24 items: 15 free legal resources (official sites, open books, free courses) + 9 VitalStack guides (4 free, 5 premium) |
| `/ai/commands/` | 10 tool cards (ChatGPT, Claude, Gemini, GitHub Copilot, Midjourney, Perplexity free; Cursor, Stable Diffusion, terminal agents, 25 power moves premium), 108 commands |
| `/ai/prompts/` | Prompt Bazaar: 42 prompts in 13 categories (27 free, 15 premium), each with the tool and "what you get" |
| `/ai/motion/` | Motion Studio: 16 animated sections (7 free, 9 premium) with live previews, code, AI prompt, download and full-screen view |

**Premium:** any paid VitalStack plan unlocks everything. Guests and free readers see the title, summary and an Unlock card. Premium text, prompts, command rows and code are never sent to their browser; premium motion shows a poster image.

**Admin:** wp-admin → AI Hub → Add item (section, category, tool, premium checkbox). Items appear above the built-in ones. AI Hub → Overview shows counts.

**Security:**
- Motion code runs in `sandbox="allow-scripts"` iframes with a CSP that blocks all network access.
- The full-screen view sends a CSP `sandbox` header.
- Only admins (`unfiltered_html`) can save motion code.
- Admin saves check a nonce and capability.
- Semgrep: 0 findings.

**SEO:** each page has its own title, description, canonical and share image. The pages are added to wp-sitemap.xml; full-screen previews are noindex.

**Tests:** `tests/aihub.e2e.js`, 28/28 (gating as guest/member/expired, filters, search, copy, dialogs, download, header link, sitemap, SEO, no JS errors). Screenshots at 1440px and iPhone 13 show no sideways scroll.
