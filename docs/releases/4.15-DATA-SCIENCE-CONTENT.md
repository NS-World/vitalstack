4.15.0 is 4.14.1 plus new learning content and a premium "Module guide". The same changes are in
5.0.0-dev.

## 3. Premium "Module guide" on every premium lesson

Each of the 39 premium modules (Data Scientist, Gen AI Developer and Agentic AI Engineer) now
opens with a **Module guide** card:

- **📜 A short history:** key dates and people, for example:
  - Statistics: Pascal and Fermat (1654) … Gosset's t-test at Guinness (1908);
  - RAG: word2vec (2013) → FAISS (2017) → the RAG paper (2020);
  - MCP: introduced in November 2024.
- **⚙️ How it works:** a numbered flow, for example RAG: documents → chunks → embeddings →
  vector DB → retrieve → prompt → answer with sources.
- **🧰 Where to run it:** Colab, Jupyter, Power BI Desktop, PySpark and so on, with a link to the
  new setup lessons.
- **💼 Used at work for:** real jobs that use it.

How it behaves:

- **Open or folded:** the card is open on a module's first lesson and folded on the others (one
  tap opens it).
- **Locked readers see it too:** readers without access see it above the lock, so they see the
  depth of the module before buying. This helps premium sales.
- **No re-import needed:** the content lives in the theme (`data/module-guides.php`), so it shows
  on lessons that are already on the site.
- **Free lessons:** they don't get the card.

## 4. Getting the new lessons onto UAT and PROD

New lessons come in through the theme's starter content (existing lessons are never overwritten):

1. Upload `vitalstack-theme-v4.15.0.zip` → **Replace current with uploaded**.
2. **Appearance → VitalStack Setup → Import starter content**.
   - It adds only the 8 new lessons: 4 setup and 4 charts.
   - It reports "Skipped … items that already exist".
3. Purge LiteSpeed and the CDN.
4. **Check:**
   - **All courses → Data & AI** shows **Data Science Setup**;
   - a premium lesson (for example the first Statistics lesson) shows the **Module guide**;
   - the lesson "Parts of a Whole" shows its four charts.
