Site: https://orchid-toad-489394.hostingersite.com/, running theme 4.12.0.

## How it was checked

- **Crawl:** 120 internal pages, checking status codes and PHP errors in the HTML.
- **Responsive browser checks:** 27 page types at 10 widths, 320 to 1920px:
  - horizontal overflow;
  - elements off the screen;
  - JavaScript errors;
  - broken images and failed requests.
- **Popups and panels:** the phone menu, search, all-courses panel, theme popover and focus-sounds
  panel, at 5 widths.
- **Speed:**
  - mobile, on a slow 4G connection with the phone CPU slowed 4x;
  - load time, LCP and layout shift (CLS) on 17 page types, phone and laptop.
- **Security (read-only):**
  - security headers;
  - user enumeration;
  - exposed files;
  - direct access to theme PHP files;
  - the payments REST API.

## Site settings to fix before PROD (not code)

1. **About Us, Privacy Policy, Terms, Disclaimer and Refund Policy pages are missing on UAT**
   (404). AdSense rejects sites without them. Publish them in Pages, then fill the placeholders:
   "[your pen name]" and "[one honest line about you…]". Without them, the footer only shows
   "Contact Us".
2. **Pages are cached in visitors' browsers for 7 days** (`cache-control: public,
   max-age=604800` on HTML). After a deploy, returning visitors can keep seeing the old page for
   up to a week, and a visitor who just signed in may still see "Sign in".
   - In LiteSpeed Cache → Browser, keep browser caching for CSS, JS and images only.
   - In hPanel → CDN, do not cache HTML in the browser for more than about 10 minutes.
   - Purge all caches after every deploy.
3. **The Pro Yearly price on UAT is ₹4,999.** The theme default is ₹2,999, so it was changed in
   Settings → VitalStack Payments. Check that this is the price you want on PROD.
4. **Optional hardening:**
   - Delete `readme.html` and `license.txt` from the WordPress root; they reveal the WordPress
     version.
   - In hPanel, turn off the `X-Powered-By: PHP/8.3.36` header.

## Security: nothing open

- **User list hidden:** `/wp-json/wp/v2/users` returns 404 and `?author=1` redirects to the home
  page.
- **XML-RPC is off:** `xmlrpc.php` returns 405.
- **Private files are blocked:** `.env`, `debug.log`, backups and the uploads folder listing all
  return 403.
- **Theme PHP files run nothing when opened directly:** they return an empty page because of the
  ABSPATH guard. The theme folder index returns a 500 with no details shown.
- **Headers in place:**
  - HSTS
  - `X-Frame-Options: SAMEORIGIN`
  - `nosniff`
  - Referrer-Policy
  - Permissions-Policy (payments only on Razorpay)
- **The price quote API** only returns a label. Orders still need login, a nonce and the server's
  own price.

## Deploying 4.12.1

1. Back up the site in hPanel.
2. Go to Appearance → Themes → Add New → Upload, choose `vitalstack-theme-v4.12.1.zip`, and pick
   **Replace current with uploaded**.
3. LiteSpeed Cache → Purge All, and hPanel → CDN → Purge.
4. Check `/tools/python-online-compiler/` and `/games/` on a phone. On a 1024px laptop, check that
   "Sign up" is fully visible. Open any wrong address, such as `/abc-xyz/`, to see the 404 page
   with Byte and the game.

4.12.1 is 4.12.0 plus the changes in `docs/releases/4.12.1-hotfix.patch` (fixes, the game and the 404 character), and nothing else. The
same fixes are also in 5.0.0-dev.
