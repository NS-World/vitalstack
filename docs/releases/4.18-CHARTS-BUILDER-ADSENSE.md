## 1. Real charts and diagrams in the data science modules

Before 4.18, only Data Visualization had charts. Now **32 more lessons** each have a "See it as a
chart" section: a chart drawn by the lesson's own Python code, which was run and checked.

| Module | Lessons | What the charts show |
|---|---|---|
| Statistics | 4 | Mean vs median with an outlier, law of large numbers, what "95% confident" means, where a p-value comes from |
| Machine Learning | 5 | The ML workflow (diagram), a regression line with its errors, overfitting curve, decision boundary, iris petals and feature importance |
| EDA | 4 | Missing values and impossible values, IQR outlier fences, scaling before/after, order hours that suggest features |
| ML in Depth | 7 | Line vs sigmoid, a drawn decision tree (diagram), SVM margin and support vectors, k-means clusters and elbow, PCA scree plot, ROC curves, permutation importance |
| Time Series | 3 | Trend and festive season, differencing and ACF, a forecast against the real values |
| Deep Learning | 5 | Activation functions and XOR learning, training curves, a CNN edge filter on real digits, sequence windows (diagram), learning rate |
| NumPy | 2 | Normalising data, the week's sales with mean/median |
| pandas | 2 | groupby → chart, revenue by city |

**How they reach your site:**

- Lessons already on the site get the charts straight away; no re-import is needed.
  - The sections are kept in the theme (`data/lesson-charts.php`).
  - A filter adds each one to its lesson, just before the lesson's "Summary".
- The protected premium lesson view shows them too.
- Nothing is doubled and the database is never changed: a lesson that already has the chart (imported later, or edited by hand) is left as it is.
- Charts load lazily, scale to the screen, and have alt text.

The `tools/build_lesson_charts.py` script rebuilds the data file from the lessons.

## 3. AdSense readiness

- **Short interview problems get more value:** the four shortest problems (Contains Duplicate,
  Valid Anagram, Group Anagrams, Top K Frequent Elements) gain a "Common mistakes and edge cases"
  section with real-world uses. Every lesson now has 300+ words of explanation (not counting code).
- **Meta descriptions:** AI City and AI Dictionary pages now have one (the only two pages without
  one in a crawl of all 608 UAT pages).
- **AdSense Helper 1.0.1:**
  - code examples like `[your code]` or `[todos, setTodos]` are no longer reported as placeholders;
  - links inside code examples (an HTML lesson's `<a href="/contact/">`) are no longer reported as broken links;
  - the thin-content check counts what visitors see (including the sections the theme adds), not code.

## 4. What the UAT audit found (and what you need to do)

These findings come from checking the live UAT copy (4.17.0).

| Check | Result |
|---|---|
| All 608 pages (lessons, paths, tools, tests, guides) | All return 200 |
| Speed | Median 0.7 s, slowest 2.2 s |
| Browser check of 130 pages, desktop and 360 px phone | No JavaScript errors, no sideways scrolling, no broken images |
| ₹/$ | US and UK visitors see $, Indian visitors see ₹ (it follows the visitor's location, not the WordPress timezone setting) |
| Placeholder text | None in lessons |
| **Legal pages** (About, Privacy, Terms, Disclaimer, Refund, Cookie, Editorial) | **Still drafts on UAT, so they return 404.** Read and publish them (guide step 3) |
| Sitemap | Off on UAT because "Discourage search engines" is ticked. Untick it on PROD (guide step 1) |
| "Diwali Sale" after Diwali | The Festive plugin is set to *Force: Diwali* on UAT. Set it to *Auto* (guide step 6) |
| OTP and offer emails in spam | UAT sends from a temporary Hostinger domain with no email DNS records. On PROD use a `@vitalstack.co.in` mailbox, SMTP, and SPF/DKIM/DMARC (guide step 4) |
