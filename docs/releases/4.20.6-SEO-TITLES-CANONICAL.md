# VitalStack 4.20.6: search titles for interview problems, one canonical per learning path

An on-page audit of every sitemap URL (titles, descriptions, H1, OG image, JSON-LD, thin text,
duplicates) found two things to fix. Nothing on the pages themselves changes.

- **Interview problem lessons** (51): the page title now matches what people search for, e.g.
  "Two Sum: Python, Java, C++ & JS Solution". Before, "Binary Search" was used twice (concept + problem).
- **Learning-path archive with a landing page of the same name** (`/tutorial-category/dsa-problems/`
  and `/dsa-problems/`): the archive's canonical points to the landing page, and the archive leaves the sitemap.
  This fixes "Duplicate without user-selected canonical".

New file `inc/seo-extra.php`. It steps aside when an SEO plugin (Yoast, Rank Math, AIOSEO, SEOPress) is active.

## Tests
- Sitemap: 478 URLs, all 200, indexable, with a self canonical. 0 duplicate titles, 0 duplicate descriptions.
- Full-site 1068 checks, pages 189, sign-in flow 40/40: all pass.
