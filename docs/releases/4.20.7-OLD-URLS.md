# VitalStack 4.20.7: old site URLs cleaned up for Google

Built from the Search Console exports of 18 Nov 2026 (404: 167, 5xx: 13, crawled-not-indexed: 114).
New file `inc/old-urls.php`. Only requests that would be a 404 are touched, so every existing page stays as it is.

| Old URL type | Now |
|---|---|
| `/news-page/…`, `/category/technology/…` (old blog listing, pages, filters) | 301 to `/blog/` |
| Old lesson/guide URLs with a clear new home (Java, MongoDB, HTML, React tutorials, `/terms-and-conditions/`, `/tutorials-page/`, `/free-ai-tools-for-students-2026/`, …) | 301 to the matching learning path or page |
| Gone for good: old tags, health section, news categories, deleted authors, lorem-ipsum test pages, links cut off mid-word, `?subcat=` / `?news_cat=` filters, old root-level posts, old theme folder | **410 Gone** (visitors see the normal page-not-found screen) |
| Feeds (`/feed/`) | still work for readers; header `X-Robots-Tag: noindex, follow` |
| Date archives (`/2026/03/`) | `noindex, follow` |
