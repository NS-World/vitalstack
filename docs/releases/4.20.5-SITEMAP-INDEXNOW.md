# VitalStack 4.20.5: clean sitemap + one IndexNow batch

## Problem
Search Console showed hundreds of "Excluded by 'noindex' tag" pages. The 135 locked premium lessons
are noindex (only a short preview is on the page, which is thin content and bad for AdSense), but the sitemap still
listed them, so Google was told "index this" and "don't index this" at the same time.

## Fix (new `inc/seo-index.php`, nothing else changed)
- Premium lessons are left out of `wp-sitemap.xml`, and out of Yoast or Rank Math sitemaps if one of them is used.
  The list is cached for 12 hours and rebuilt when lessons or paths change.
- Once after each theme update (5 minutes after an admin visit, in WP-Cron), every sitemap URL is sent
  to IndexNow (Bing and others) in one batch. Never on local or hostingersite.com domains.
  New and updated pages were already pinged one by one.

## Tests
- Local sitemap: 614 URLs → 479; every URL returns 200, is indexable, and has a self canonical
  (0 noindex, 0 redirects, 0 404).
- IndexNow batch: 479 URLs, correct host and keyLocation, 0 premium URLs, runs once per version.
- Full-site 1068 checks, pages 189, sign-in flow 40/40: all pass.
