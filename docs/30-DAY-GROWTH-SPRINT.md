## The FOLLOW LOOP (every post is built on this)

```
 STOP → "THAT'S ME" → AHA! → OPEN LOOP → TINY ACTION → REWARD → RETURN
```
1. **Stop:** bold 5-word hook + a picture that surprises in 1 second.
2. **That's me:** speak to one person ("if you're learning Python…"). Gen Z follows identity.
3. **Aha:** one useful idea, explained with daily life. Makes them feel smart → saves.
4. **Open loop:** one thing is finished **on the site**: the answer, the game, the full lesson, the test.
5. **Tiny action:** comment one word, save, or tag a friend.
6. **Reward:** instant DM with the link (ManyChat), a reply to every comment.
7. **Return:** numbered series + "next post tomorrow" on the last slide.

**Never:** fake scarcity, fake reviews, salary promises, bought followers, clickbait we don't pay off.
