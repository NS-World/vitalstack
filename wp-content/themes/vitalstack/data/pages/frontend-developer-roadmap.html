Frontend developers build everything people see and click. The path is short in topics but deep in practice: most of your time should go into building pages, not watching tutorials. The times assume about 2 hours a day.

HTML (1–2 weeks)

The structure of every page: headings, links, images, lists, tables, forms and semantic tags that help both screen readers and Google.

[[path:html]]

Mini project: a personal profile page with an about section, a list of skills and a contact form.

CSS (3 weeks)

Colours and fonts are the easy part. Spend most of this stage on the box model, Flexbox, Grid and media queries; that is what makes a layout work on every screen.

[[path:css]]

You are ready when you can rebuild the layout of a site you like from a screenshot, and it still looks right on a phone.

JavaScript (4 weeks)

The language of the browser. Learn the basics, then the DOM, events, forms, local storage and fetching data from APIs with async/await.

[[path:javascript]]

Mini project: a to-do list app that saves tasks in local storage.

React or Angular (3–4 weeks)

Most frontend jobs ask for a framework. React is the most popular and easier to start with; Angular is a complete framework used by many large companies. Pick one, finish it, and build the Course Hub project.

[[path:react]]

[[path:angular]]

Practice for interviews

Frontend interviews ask JavaScript fundamentals, a small coding task, and often a few DSA questions. Take the mock tests, then practise a few problems a week.

[[path:dsa]]

Your portfolio

Three or four projects are enough: the profile page, the to-do app, the Course Hub and one idea of your own. Host them for free on GitHub Pages, Netlify or Vercel and put the live links on your resume.
