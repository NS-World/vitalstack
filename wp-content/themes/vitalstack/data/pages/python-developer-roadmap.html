Python is the friendliest first language and opens doors to backend development, automation, data and AI. This roadmap builds the base every Python role needs. The times assume about 2 hours a day.

Python basics (4 weeks)

Syntax, data types, strings, lists, dictionaries, loops, functions, modules, files, exceptions and classes, then installing packages with pip and working with JSON and APIs.

You are ready when you can write a script that reads a file, processes the data and saves a result, with errors handled.

SQL (2 weeks)

Whatever you build in Python, the data usually lives in a database. Learn to query, join and group data.

Where to go next

With these basics you can choose a direction. For web backends, learn a framework such as Django or FastAPI from its official tutorial. For data work, learn pandas and a charting library. For AI, read the guides in the AI section of this site and start calling an AI API from your own Python script. Whichever you choose, keep building small projects and putting them on GitHub.
