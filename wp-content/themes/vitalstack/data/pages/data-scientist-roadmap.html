Data scientists turn messy data into decisions: which customers might leave, how many units to stock, which product to promote. This roadmap follows the order skills build on each other, with runnable code in every lesson. Plan on 5–6 months at 1–2 hours a day.

The rule that matters most: finish projects. Recruiters look at what you built and explained, not how many certificates you collected.

Interview preparation

  • Explain each project in 2 minutes: problem, data, approach, result, what you'd do next.
  • Practise SQL daily: joins, GROUP BY and window functions come up in almost every interview.
  • Be ready for "Why this metric?" and "How would you know the model still works next month?"
