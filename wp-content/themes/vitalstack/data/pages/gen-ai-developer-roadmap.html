Gen AI developers build products on top of large language models: support bots, document assistants, study tools and agents. You don't need to train models from scratch; you need to use them well, connect them to data, make them safe and ship them. Plan on 3–4 months at 1–2 hours a day if you already know some Python.

How to stand out

  • Put every project online with a short demo video and a README showing your eval results.
  • Show you can control cost (tokens per request) and quality (a test set with a pass rate).
  • Write one blog post per project explaining a mistake you fixed. It proves real experience.
