💻 NOW IN REAL CODE
4/5

Ordering, in
4 lines of Python.

order.py
import requests

# 📝 tell the waiter what you want
r = requests.get("https://api.example.com/pizza")

# 🍕 the plate comes back
print(r.status_code)   # 200 = order served
print(r.json())
output
200
{"dish": "Margherita", "price": 9.5}
