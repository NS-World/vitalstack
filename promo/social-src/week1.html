🐞 SPOT THE BUG · #1
1/2

Why did my original
list change?

backup.py
scores = [90, 85, 70]
backup = scores        # "save a copy"
backup.append(100)

print(scores)
output
[90, 85, 70, 100]   😱

Find the bug in 10 seconds.
Comment your fix 👇

Answer →
vitalstack.co.in
✅ THE ANSWER
2/2

= doesn't copy.
It shares.

scores and backup are two names for the same list. Change one, you change "both".

fixed.py
backup = scores.copy()   # ✅ a real copy
# also works:
backup = scores[:]
backup = list(scores)
