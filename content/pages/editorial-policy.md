VitalStack publishes beginner-friendly guides to programming and
artificial intelligence. This page explains how those guides are made.

## What we publish

- **Tutorials** organised into learning paths, from first steps to small projects.
- **Guides** explaining AI concepts and tools and how to use them well.
- **Career guides** on skills and roadmaps for getting into tech.

We do not publish sponsored content disguised as editorial content. If
we ever publish a sponsored post or use affiliate links, it will be
clearly labelled.

## How a guide is made

1. **A real question.** Each guide starts from a question beginners
   actually ask (from search data, comments or messages).
2. **Research.** We read official documentation and primary sources
   first, and link to them where it helps the reader.
3. **Drafting.** We use AI tools to help with research, outlines and
   first drafts. AI output is never published as-is.
4. **Testing.** Every code example is run before publishing. Tool
   walkthroughs are checked against the current version of the tool.
5. **Editing.** A person reviews every article for accuracy, clarity and
   usefulness, and takes responsibility for what is published.

## Updates and corrections

Technology changes quickly. We review popular guides regularly and
update them when something changes. The date at the top of each article
shows when it was last updated.

If you find a mistake, please tell us through the
[contact page](/contact-us/). We fix confirmed errors quickly, and note
significant corrections in the article.

## Advertising

VitalStack is free to read and is supported by display advertising
(Google AdSense). Advertisers have no influence on what we write, and
ads are always visually separate from article content.
